# Mission Control Documentation

This folder contains **design docs** and **feature docs** for every major module in Mission Control.

## Principles
- Every feature should have:
  - a **Feature Doc** (what the user sees + how to use)
  - a **Design Doc** (data model, flows, decisions, tradeoffs)
- Keep docs short, actionable, and in sync with the code.
